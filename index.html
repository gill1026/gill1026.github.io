8번의 교육으로, 내 코드로 트랙 한 바퀴

이론 설명을 길게 듣는 시간이 아닙니다. 실제 대회에서 달렸던 차의 주행 기록을 화면에 띄워놓고, 코드가 무엇을 보고 어떻게 판단하는지 눈으로 확인하면서 배웁니다.

총 8회 · 회당 1시간 오프라인 사전 지식 필요 없음

코드가 보는 것을 눈으로

1–2회
1회

자율주행이 뭔지, 그리고 개발 환경 만들기

  • 차가 스스로 달리는 원리를 인지 → 판단 → 제어 세 단계로 나눠 이해합니다
  • 개발 도구 ROS2를 설치합니다
  • 미리 찍어둔 실제 주행 기록(rosbag)을 재생하면서, 코드가 단계마다 무엇을 보고 있는지 화면으로 확인합니다
2회

코드 한 줄이 무엇을 하는지 화면으로 확인하기

  • 카메라 전처리 — 영상에서 차선만 또렷하게 남기기
  • 차가 차선 중앙에서 얼마나 벗어났는지 계산하기
  • 조향 안정화 — 핸들이 좌우로 덜덜 떨리지 않게 만들기
중간 결과를 하나하나 화면에 띄워 확인하기 때문에, 코드를 눈으로 따라갈 수 있습니다.

진짜 차량에 올리기

3회

설계도를 그리고, 차를 움직이기

  • ROS2 노드와 토픽 설계도 그리기 — 프로그램을 어떤 조각으로 나눌지 정하는 작업입니다
  • 실제 차량에 코드를 넣고 모터가 제대로 도는지 확인
  • 센서에서 들어오는 데이터가 정상인지 화면으로 점검

대회에서는 이렇게 했다

4–7회
4회

안 되는 코드를 되게 만드는 과정

  • 코드 짜고, 돌려보고, 원인 찾고, 다시 고치는 디버깅 과정을 그대로 보여줍니다
  • 그 과정에서 왜 rosbag이 꼭 필요했는지
  • 빠르게 달릴 때 흔들리지 않도록 제어값 맞추기(PID 세팅)
5회

대회의 미션들, 어떻게 풀었나

  • 장애물 회피 주행
  • 주차 미션
  • 신호등을 알아보게 만들기 — YOLO 학습 과정
  • 라바콘 사이를 통과하는 주행
6회

실전에서 몸으로 배운 것들

  • git으로 코드 관리하기

  • colcon build, alias 같은 사소하지만 중요한 습관

이런 말이 나옵니다

지금 몰라도 괜찮습니다. 교육 중에 하나씩 설명합니다.

ROS2
카메라·모터·프로그램이 서로 데이터를 주고받게 해주는, 로봇 개발의 공용어 같은 도구입니다.
노드 · 토픽
프로그램을 기능별 조각(노드)으로 나누고, 그 조각들이 주고받는 데이터 통로(토픽)를 말합니다.
rosbag
차가 실제로 달릴 때 들어온 카메라·센서 데이터를 통째로 녹화해둔 파일입니다. 나중에 그대로 재생할 수 있습니다.
전처리
원본 영상을 그대로 쓰지 않고, 판단에 필요한 정보만 남도록 미리 가공하는 단계입니다.
조향 안정화
핸들 조작이 급하게 튀지 않도록 값을 조절하는 것. 자율주행이 "잘 달린다"는 느낌을 좌우합니다.
PID
목표에서 벗어난 만큼 얼마나 세게 되돌릴지 정하는 방법. 세 개의 값을 조절해 맞춥니다.
YOLO
사진 속 물체가 무엇이고 어디 있는지 빠르게 찾아내는 AI 모델입니다. 신호등 인식에 씁니다.
