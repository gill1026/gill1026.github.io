한양대학교 ERICA소프트웨어융합대학 자율주행 학회

8번의 교육으로,
내 코드로 트랙 한 바퀴

자율주행이 처음이어도 괜찮습니다. 원리를 훑고, 코드를 뜯어보고, 직접 만든 코드를 실제 대회 트랙에서 달리게 하는 데까지 8번이면 됩니다.

총 8회 · 회당 1시간 오프라인 사전 지식 필요 없음
STAGE 1 자율주행 감 잡기 1–3회
1회
자율주행의 큰 그림 그리기
차가 스스로 달린다는 건 결국 보고 → 판단하고 → 움직이는 세 단계입니다. 이 구조를 먼저 잡고, 자율주행을 만드는 두 갈래 방식을 비교해 봅니다. 개발 환경 ROS2도 이날 함께 설치합니다.
룰베이스
사람이 "차선이 왼쪽으로 치우치면 오른쪽으로 꺾어라" 같은 규칙을 하나하나 짜주는 방식입니다.
E2E · VLA
규칙을 알려주는 대신, AI가 주행 데이터를 보고 스스로 운전을 배우게 하는 방식입니다.
ROS2
카메라·모터·프로그램이 서로 데이터를 주고받게 해주는, 로봇 개발의 공용어 같은 도구입니다.
2–3회
완성된 코드 열어보고 굴려보기
이미 돌아가는 룰베이스 자율주행 코드를 함께 읽습니다. 그다음 시뮬레이터 안에서 직접 실행해 봅니다. 컴퓨터 속 가상 트랙이라 몇 번을 박아도 부서지는 게 없습니다.
STAGE 2 코드 뜯어서 내 것으로 4–6회
4회
카메라가 찍은 영상 다듬기
사람 눈에는 대번에 보이는 차선이 컴퓨터에게는 그저 숫자 덩어리입니다. 필요 없는 부분을 걷어내고 차선만 또렷하게 남기는 작업을 다룹니다.
전처리
원본 영상을 바로 쓰지 않고, 판단하기 좋은 형태로 미리 손질하는 단계입니다.
5회
차선 한가운데로, 흔들리지 않게
차가 중앙에서 얼마나 벗어났는지 숫자로 계산하고, 그만큼 핸들을 꺾습니다. 이때 너무 급하게 꺾으면 좌우로 덜덜 떨리며 달리게 되는데, 이걸 부드럽게 잡는 방법을 배웁니다.
조향 안정화
핸들 조작이 튀지 않도록 다듬는 것. 자율주행이 "잘 달린다"는 느낌을 좌우하는 부분입니다.
6회
내 코드를 진짜 자동차에 올리기
지금까지 만든 코드를 ROS2 패키지로 묶어 스케일카에 적용합니다. 손바닥만 하지만 카메라로 보고 스스로 달리는, 진짜 자율주행차입니다. 화면 밖에서 처음으로 내 코드가 움직이는 순간입니다.
STAGE 3 트랙에서 직접 7–8회
7회
대회에서 부딪힌 문제, 그때 어떻게 풀었나
차선 주행, 주차, 장애물 회피. 선배들이 실제 자율주행 대회에서 마주친 상황과 그때 쓴 해법을 그대로 뜯어봅니다.
8회
대회 트랙에서, 내가 만든 코드로 완주
실제 대회에 썼던 트랙 위에 각자의 스케일카를 올립니다. 8번 전에는 아무것도 몰랐던 코드가 혼자서 한 바퀴를 돕니다.

ORDA에서 더 할 수 있는 것

  • 대회에 직접 나가본 선배들에게 물어보고, 경험을 그대로 전해 듣기
  • 요즘 자율주행 기술이 어디까지 왔는지, 무엇을 공부하면 좋을지 함께 정리
  • 학회가 여는 교내 자율주행 경진대회와 전국 대회 참가
